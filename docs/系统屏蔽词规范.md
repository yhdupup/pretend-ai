# 系统屏蔽词规范

> 版本：v1.0  
> 更新日期：2026-09-13  
> 目标：降低本工具被用于索取资金、套取凭证或诱导远程控制的风险。

## 1. 生效范围

系统检查所有由 A 控制且最终会展示给 B 的文字，包括：

- 假 AI 名称与开场白；
- A 发送的回复正文；
- 展示给 B 的深度思考内容；
- 揭晓时的 A 名称与留言。

B 输入的问题不做替换，A 需要看见对方的原始问题才能判断风险。

## 2. 处理方式

- 命中词整体替换为全角星号 `＊`，其余内容照常发送；
- 支持简体、常见繁体、英文缩写及不区分英文大小写；
- 支持识别字符间插入空格或常见标点的简单规避，例如“转 账”“支-付-宝”；
- A 端提示本次内容已触发安全过滤，但不在日志中记录命中词或原文；
- 过滤在服务端执行，直接调用接口不能绕过；B 端公开输出再过滤一次作为兜底。

屏蔽词只能降低风险，不能替代举报、审计、使用提示或人工判断。谐音、图片、复杂变体和上下文诈骗仍可能绕过。

## 4. 维护规则

运行时唯一词表位于 `coding/src/server/security/content-filter.ts`。调整词表时必须同步更新本文档，并至少验证：

1. 正常命中、重复命中、大小写和简繁体；
2. 插入空格或标点后的命中；
3. 相邻但不构成词的正常文字不被误伤；
4. A 端有提示，B 端任何公开响应都不含原词；
5. 日志不写入原文及命中词。

对于误伤率高的单字和通用词，应先评估实际场景。首版保留“钱／錢”是明确的产品安全决定。
